# Group5-GewuEdu
大作业5:具身智能教育

### 目录结构约定
每个人在提交自己的进展时，请确保文件存放在指定位置：

个人文档:存放在readme/姓名拼音.md

静态资产:所有图片、视频等素材请存放在 assets/你的姓名拼音/ 目录下，并根据类型划分子文件夹（如 imgs/, videos/）。

### 仓库结构规范


```text
.
├── assets/                # 静态资源根目录
│   ├── memberA/           # 每个人创建自己的姓名文件夹（建议拼音）
│   │   ├── imgs/          # 存放图片素材
│   │   └── videos/        # 存放演示视频
│   ├── memberB/
│   │   ├── imgs/
│   │   └── videos/
│   ├── memberC/
│   └── memberD/
│
├── ppts/                   # 存放每周汇报ppt
│   ├── Group5_GewuEdu_2026_3_27.pptx
│   ├── Group5_GewuEdu_2026_4_3.pptx
│   └──
│   ```
│
├── readme/                 # 个人进度文档根目录
│   ├── memberA.md          # 每个人的详细进展说明
│   ├── memberB.md
│   ├── memberC.md
│   └── memberD.md
│
├── weekly_report.md       # 项目周报
│  
└── README.md              # 项目主页（包含此规范说明）

```
